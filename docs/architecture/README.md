# Architecture Diagrams

This folder contains architecture diagrams for the AgenticAI project.

## Conventions

- Use `.png` or `.svg` for rendered diagrams
- Use `.mermaid` or `.md` (with Mermaid code blocks) for source diagrams
- Name files descriptively: `pipeline_overview.mermaid`, `claude_agent_flow.svg`, etc.

## Updating CLAUDE.md

When a new diagram is added or an existing one significantly changes:
1. Add or update the reference in the **Architecture** section of `CLAUDE.md`
2. Include a one-line description of what the diagram shows
